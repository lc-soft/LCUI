# doc-viewer 顶栏图标与 star 数设计

日期：2026-11-21
状态：待实现

## 背景

doc-viewer 顶栏当前右侧显示纯文本版本号（`3.0.0-alpha.0`）和文本链接 `GitHub`。需要：

- 版本号移到 Home 页 hero 标题 `LCUI` 旁，用 badge 展示；
- GitHub / Gitee 改为单色图标链接；
- 图标旁显示 star 数，获取不到时只显示图标；
- 图标在浅色/深色主题下分别使用黑色/白色版本。

## 决策

| 主题 | 决策 |
|---|---|
| 图标显示 | CSS `background-image` 指定 PNG 路径，`.dark` 父选择器切换深色版 |
| 图标形式 | 单色双版本（浅色黑版、深色白版） |
| 版本号 | 从顶栏移除，放到 Home hero 标题右侧的 badge |
| star 获取 | 构建期由 Node 脚本抓取，带文件缓存和 TTL；运行时不发网络请求 |
| 图标生成脚本 | 一次性本地工具，**不提交到 git**；生成后的 PNG 提交 |
| 视觉验证 | 不做离屏截图，由人工肉眼确认 |

## 图标资源

目录：`examples/doc-viewer/app/assets/`

- `github-mark-black.png`、`github-mark-white.png`
- `gitee-mark-black.png`、`gitee-mark-white.png`

来源：

- GitHub 官方 brand 资源（`https://github.com/logos`）；
- Gitee 使用已有的 `logo_gitee_g_white.png`，再用一次性脚本生成黑色版。

图标按 16×16 显示，源图可以是 32×32 或 64×64。

### 一次性生成脚本（不入库）

本地脚本读取 PNG，重写 RGB（黑 0 / 白 255），保留 alpha，输出对应颜色版本。只用于生成上面四个文件，生成后删除，不加入仓库。

### 显示样式

```css
.navbar-icon {
  width: 16px;
  height: 16px;
  background-repeat: no-repeat;
  background-position: center;
  background-size: 16px 16px;
}

.navbar-icon-github {
  background-image: url("../assets/github-mark-black.png");
}

.dark .navbar-icon-github {
  background-image: url("../assets/github-mark-white.png");
}

/* Gitee 同理 */
```

LCUI 已支持 `background-image` / `background-size` / `background-position` /
`background-repeat`，PNG 由 pandagl 解码，CSS `url()` 由构建期 `postcss-url`
重写为输出资源路径。

## 顶栏改造

`examples/doc-viewer/app/components/navbar.tsx` / `navbar.css`：

- 删除 `navbar-version` 节点和对应 compact 规则；
- 右侧新增两个链接：


- hover 背景复用 `.navbar-link:hover`。

## star 数据（构建期）

### 脚本

`scripts/fetch-repo-stars.js`（提交到仓库）：

- 缓存：`examples/doc-viewer/.cache/repo-stars.json`（加入 `.gitignore`）
- TTL：默认 24 小时，支持 `--max-age <hours>`
- 数据源：
  - GitHub `GET https://api.github.com/repos/lc-soft/LCUI` → `stargazers_count`
  - Gitee `GET https://gitee.com/api/v5/repos/lc-soft/LCUI` → `stargazers_count`
  - GitHub 请求带 `User-Agent`
- 失败策略：
  - 单源失败：保留该源旧值
  - 无旧值且请求失败：写 `null`
  - 脚本始终 exit 0，不阻塞构建
- 输出：`examples/doc-viewer/app/components/repo-stars.generated.ts`（不提交）

```ts
// Generated by scripts/fetch-repo-stars.js
export const repoStars: {
  github: number | null;
  gitee: number | null;
} = { github: 1234, gitee: 567 };
```

### 构建接入

`package.json`：

```json
"doc-viewer:stars": "node scripts/fetch-repo-stars.js",
"doc-viewer:compile-tsx": "npm run doc-viewer:stars && cd examples/doc-viewer && lcui build --skip-xmake",
"doc-viewer:compile-docs": "npm run doc-viewer:stars && cd examples/doc-viewer && npm run compile"
```

更新 `examples/doc-viewer/AGENTS.md`：直接运行 `lcui build` 前需要先生成 star 数据。

## 风险

- CI 无网络时 star 为 `null`，界面只显示图标，构建不受影响；
- GitHub 未认证 API 限流 60 次/小时，24h 缓存足够；
- 图标为单色 PNG，主题切换依赖 `.dark` 选择器，不引入图片着色能力。

# Alert

Displays a non-blocking status, result, or risk message within the current content area.

<WidgetExample name="alert-basic" />

## Use cases

- **Suitable**: showing a save result, a permission reminder, or a recoverable error
- **Suitable**: offering a follow-up action next to local content
- **Not suitable**: notifications that need a global queue or auto-dismiss

## Usage

```tsx
import { Alert, AlertContent, AlertDescription, AlertTitle } from "@lcui/react"
```

```tsx
<Alert>
  <AlertContent>
    <AlertTitle>Payment successful</AlertTitle>
    <AlertDescription>Your payment has been processed.</AlertDescription>
  </AlertContent>
</Alert>
```

## Composition

Use the following composition to build an `Alert`:

```
Alert
├── Icon
├── AlertContent
│   ├── AlertTitle
│   └── AlertDescription
└── AlertAction
```

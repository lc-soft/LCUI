# InputGroup

Combines an input, icons, helper text, buttons, and menus into a single bordered input area.

<WidgetExample name="input-group-demo" />

## Use cases

- **Suitable**: Search fields, amount inputs, password fields, comment boxes, and other inputs with leading/trailing icons or actions
- **Suitable**: Keeping an input, description, counter, unit, or submit button inside one visual container
- **Not suitable**: A plain input without addons (use `TextInput` directly)
- **Not suitable**: Multi-field form layouts (compose with `Field` / `FieldGroup`)

## Usage

```tsx
import {
  Icon,
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupKbd,
  InputGroupText,
  InputGroupTextarea,
} from "@lcui/react"
```

```tsx
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <Icon name="search" />
  </InputGroupAddon>
</InputGroup>
```

## Composition

Use the following composition to build an `InputGroup`:

```
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
├── InputGroupText
└── InputGroupKbd
```

## Caveats

:::note
**Focus and disabled states are maintained in C**. LCUI has no `:focus-within` or `:has()`, so the root tracks `focused` through bubbling `focus`/`blur` events and tracks `has-disabled` from its controls.
:::

:::info
**Addons are reordered automatically**. Whether the input or an addon is declared first, the root places inline-start / block-start addons before the input and inline-end / block-end addons after it.
:::

:::caution
**Do not mix block and inline addons**. If both are used, block layout wins and inline addons are laid out as rows.
:::

:::caution
**Use one input control per group**. Addon click-to-focus only targets the first matching control; disabled scanning covers the whole subtree.
:::

:::note
**Multi-line input is still limited**. `InputGroupTextarea` is based on the multi-line `TextInput`; the XML variant shows the structure only, while the C/TSX factories enable multi-line editing.
:::

# AlertDialog

A modal dialog that interrupts the user with important content and expects a response.

<WidgetExample name="alert-dialog-basic" />

## Use cases

- **Use for**: confirming destructive or irreversible operations such as deletion
- **Use for**: flows that may continue only after an explicit "confirm / cancel" choice
- **Don't use for**: ordinary panels that may be dismissed with Esc or an overlay click (use `dialog`)

## Usage

```tsx
import { AlertDialog, AlertDialogTrigger, AlertDialogOverlay, AlertDialogContent, AlertDialogHeader, AlertDialogMedia, AlertDialogTitle, AlertDialogDescription, AlertDialogFooter, AlertDialogCancel, AlertDialogAction, Portal } from "@lcui/react"
```

```tsx
<AlertDialog>
  <AlertDialogTrigger>Show Dialog</AlertDialogTrigger>
  <Portal>
    <AlertDialogOverlay>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>Are you absolutely sure?</AlertDialogTitle>
          <AlertDialogDescription>
            This action cannot be undone. This will permanently delete your
            account and remove your data from our servers.
          </AlertDialogDescription>
        </AlertDialogHeader>
        <AlertDialogFooter>
          <AlertDialogCancel>Cancel</AlertDialogCancel>
          <AlertDialogAction>Continue</AlertDialogAction>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialogOverlay>
  </Portal>
</AlertDialog>
```

## Composition

Use the following composition to build an `AlertDialog`:

```
AlertDialog
├── AlertDialogTrigger
└── Portal
    └── AlertDialogOverlay
        └── AlertDialogContent
            ├── AlertDialogHeader
            │   ├── AlertDialogMedia
            │   ├── AlertDialogTitle
            │   └── AlertDialogDescription
            └── AlertDialogFooter
                ├── AlertDialogCancel
                └── AlertDialogAction
```

## Small

Use the `size="sm"` prop on the `AlertDialogContent` component to make the alert dialog narrower; the two footer buttons then stretch equally across the content area.

## Cancel and Confirm Callbacks

`AlertDialogCancel` and `AlertDialogAction` close the dialog and then emit the `cancel` / `action` events respectively; handling the business result is up to the caller. Plain buttons outside the subtree can join the flow through the `data-dialog-cancel` / `data-dialog-action` association keys.

## Caveats

:::caution

**Pressing Esc or clicking the overlay does not close the alert dialog**; the user can only choose cancel or confirm, while an explicit `ui_dialog_close()` still works. Open/close animations and focus traps are not implemented.

:::

:::note

Confirm actions are synchronous events; waiting on async results or multi-step confirmations is out of scope and can be built on top of the `action` event in the application layer. The Media section from shadcn relies on a two-column CSS grid layout, which LCUI does not support; the `AlertDialogMedia` icon stacks vertically and centers (see the Destructive example). RTL layouts are not supported either.

:::

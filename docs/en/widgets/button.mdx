# Button

A clickable button widget, typically used to trigger an action.

<WidgetExample name="button-basic" />

## Use cases

- **Suitable**: users click to perform an action (submit a form, open a page, toggle a state)
- **Suitable**: interactive entry points in toolbars, dialogs, and navbars
- **Not suitable**: non-interactive text display (use `text` instead)

## Anatomy

```tsx title="Anatomy"
import { Button } from "@lcui/react";

<Button />
```

Button is a single-line widget composed of a background layer and text content. The `:hover` / `:active` pseudo-classes toggle the background color to provide click feedback.

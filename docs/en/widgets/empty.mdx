# Empty

Provides centered, composable placeholder content for states such as no data or no search results.

<WidgetExample name="empty-basic" />

## Use cases

- **Suitable**: when a list, search result, or content area is empty
- **Suitable**: guiding the user to create their first item
- **Not suitable**: a state where data is still loading (use a loading indicator)

## Usage

```tsx
import {
  Button,
  Empty,
  EmptyAction,
  EmptyDescription,
  EmptyMedia,
  EmptyTitle,
  Text,
} from "@lcui/react"
import { Folder } from "@lcui/fluent-icons"
```

```tsx
<Empty>
  <EmptyMedia>
    <Folder />
  </EmptyMedia>
  <EmptyTitle>No data</EmptyTitle>
  <EmptyDescription>No data found</EmptyDescription>
  <EmptyAction>
    <Button><Text>Add data</Text></Button>
  </EmptyAction>
</Empty>
```

## Composition

Use the following composition to build an `Empty`:

```
Empty
├── EmptyMedia
├── EmptyTitle
├── EmptyDescription
└── EmptyAction
```

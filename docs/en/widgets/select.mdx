# Select

Select provides an expandable list of options for choosing one value from multiple candidates.

<WidgetExample name="select-basic" />

## Use cases

- **Suitable**: Choosing one value from multiple options
- **Suitable**: Forms with many options where page space should be preserved
- **Suitable**: Options that can be grouped by category
- **Not suitable**: Choosing multiple values at once (use `checkbox`)

## Usage

```tsx
import { Select, SelectTrigger, SelectValue, SelectContent, SelectGroup, SelectLabel, SelectItem } from "@lcui/react"
```

```tsx
<Select>
  <SelectTrigger>
    <SelectValue placeholder="Select a theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel>Theme</SelectLabel>
      <SelectItem value="light">Light</SelectItem>
      <SelectItem value="dark">Dark</SelectItem>
      <SelectItem value="system">System</SelectItem>
    </SelectGroup>
  </SelectContent>
</Select>
```

## Composition

Use the following composition to build a `Select`:

```
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    ├── SelectGroup
    │   ├── SelectLabel
    │   ├── SelectItem
    │   └── SelectItem
    ├── SelectSeparator
    └── SelectGroup
        ├── SelectLabel
        ├── SelectItem
        └── SelectItem
```

## Groups

Wrap a set of related options in `SelectGroup` and use `SelectLabel` as the group heading; when the panel holds several groups, use `SelectSeparator` to draw a divider between them.

<WidgetExample name="select-groups" />

## Align Item With Trigger

By default, opening a `Select` makes the popup **overlap the trigger** so the **selected item** sits at the same height as it; when nothing is selected the first item is aligned instead. If the trigger is near the bottom of the window and there is not enough room to align, the popup flips above the trigger and shows a scrollbar. Set `align-item-with-trigger` to `false` to disable aligning and expand the popup against the trigger edge.

<WidgetExample name="select-align-item" />

## Scrollable

When the options exceed the available height the popup is capped to that height and shows a scrollbar; when the trigger is near the bottom of the window the popup flips above it and uses the space available on that side.

<WidgetExample name="select-scrollable" />

## Disabled

Setting `disabled` on `Select` lowers the opacity of the trigger and stops the content panel from opening; you can also disable an individual `SelectItem`, which then cannot be selected.

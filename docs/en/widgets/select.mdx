# Select

Select provides an expandable list of options for choosing one value from multiple candidates.

<WidgetExample name="select-basic" />

## Use cases

- **Suitable**: Choosing one value from multiple options
- **Suitable**: Forms with many options where page space should be preserved
- **Not suitable**: Choosing multiple values at once (use `checkbox`)

## Usage

```tsx
import { Select, SelectTrigger, SelectValue, SelectContent, SelectItem } from "@lcui/react"
```

```tsx
<Select>
  <SelectTrigger>
    <SelectValue placeholder="Choose a theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="light">Light</SelectItem>
    <SelectItem value="dark">Dark</SelectItem>
    <SelectItem value="system">System</SelectItem>
  </SelectContent>
</Select>
```

## Composition

Use the following composition to build a `Select`:

```
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    └── SelectItem
```

# Item

A general content-row container for settings, lists, and quick actions.

<WidgetExample name="item-basic" />

## Use cases

- **Suitable**: settings entries, resource lists, and content rows with actions
- **Suitable**: combining media, a title, a description, and trailing actions
- **Not suitable**: menu items with a selected value and keyboard selection logic

## Usage

```tsx
import { Item, ItemActions, ItemContent, ItemDescription, ItemMedia, ItemTitle } from "@lcui/react"
```

```tsx
<Item variant="outline">
  <ItemContent>
    <ItemTitle>Basic Item</ItemTitle>
    <ItemDescription>A simple item with title and description.</ItemDescription>
  </ItemContent>
  <ItemActions><button>Action</button></ItemActions>
</Item>
```

## Composition

Use the following composition to build an `Item`:

```
Item
├── ItemMedia
├── ItemContent
│   ├── ItemTitle
│   └── ItemDescription
└── ItemActions
```

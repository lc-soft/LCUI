# Progress

A linear progress bar widget used to indicate the completion of a task such as file uploads or loading states.

<WidgetExample name="progress-basic" />

## Use cases

- **Suitable**: file upload/download, installation, or any long-running task that needs progress feedback
- **Suitable**: form submission or async operations that need a wait indicator
- **Not suitable**: scenarios that require precise numeric values or indeterminate progress (use `text` to render manually)

## Usage

```tsx
import { Progress } from "@lcui/react"
```

```tsx
<Progress value={20} />
```

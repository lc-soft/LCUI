# Accordion

Vertically stacked sections with headers and content, expanding one or more panels at a time.

<WidgetExample name="accordion-demo" />

## Use cases

- **Suitable**: FAQ pages, grouped settings, billing details, and other pages where content is revealed by a header
- **Suitable**: Long content where only part of it needs to be read at a time
- **Not suitable**: Side-by-side tabs (use `select` or a future tabs widget)
- **Not suitable**: Modal confirmation or blocking flows (use `dialog`)

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@lcui/react"
```

```tsx
<Accordion defaultValue="shipping">
  <AccordionItem value="shipping">
    <AccordionTrigger>What are your shipping options?</AccordionTrigger>
    <AccordionContent>
      We offer standard, express, and overnight shipping.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## Composition

Use the following composition to build an `Accordion`:

```
Accordion
├── AccordionItem
│   ├── AccordionTrigger
│   └── AccordionContent
└── AccordionItem
    ├── AccordionTrigger
    └── AccordionContent
```

## Caveats

:::note
**No expand/collapse animation**. LCUI's CSS engine does not support transitions or animations, so state changes are instant.
:::

:::info
**Initialization does not emit events**. `defaultValue` / `value` and item `open` during parsing only synchronize state; `change` is emitted only for user clicks, Enter/Space, or `ui_accordion_item_set_open()`. `ui_accordion_set_value()` is a silent controlled sync.
:::

:::info
**The `change` payload is the value of the toggled item**. The root `value` attribute holds the full comma-separated set; read it with `ui_accordion_get_value(root)` inside a listener. Setting multiple values at once does not emit one event per item.
:::

:::tip
**`data-accordion-trigger` is an LCUI extension**. It is a behavior marker only and does not participate in CSS selectors; custom triggers must handle focus themselves and use `accordion-item:open` / `accordion-item:closed` for expanded-state styles.
:::

:::caution
**Keyboard support is limited to Enter/Space**. Triggers can be focused with Tab; arrow keys and Home/End roving tabindex are not implemented. When single mode auto-closes other items, those items do not emit additional `open`/`close` events.
:::

# ButtonGroup

Group related buttons, inputs or popup controls into a visually continuous button group.

<WidgetExample name="button-group-demo" />

## Use cases

- **Use**: merging adjacent actions of the same kind, such as Archive / Report / Snooze
- **Use**: split buttons, input + action button, or Select + input + send button
- **Use**: nesting multiple ButtonGroups to create group spacing
- **Don't use**: switching state between several options (use ToggleGroup or RadioGroup)
- **Don't use**: buttons that need independent spacing and must not share borders (use Button directly)

## Usage

```tsx
import {
  Button,
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from "@lcui/react"
```

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## Composition

Use the following composition to build a `ButtonGroup`:

```
ButtonGroup
├── Button or Input or InputGroup or Select
├── ButtonGroupText
├── ButtonGroupSeparator
└── ButtonGroup
```

## Caveats

:::note
**ButtonGroup is not a ToggleGroup.** It only handles layout and visual merging and keeps no selection state; use RadioGroup or a future ToggleGroup for state switching.
:::

:::info
**Edge radii are based on direct children.** The root adds an internal marker class to direct children and uses LCUI's `first-child` / `last-child` statuses to compute edge radii and adjacent borders. Buttons wrapped in an ordinary wrapper do not participate.
:::

:::caution
**Keep separators in the middle.** Placing them at the start or end would consume the first/last button's corner radius.
:::

:::caution
**Horizontal separators in a vertical group must be set explicitly.** `ButtonGroupSeparator` is vertical by default; set `orientation="horizontal"` inside a vertical group.
:::

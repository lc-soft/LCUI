# Sidebar

A composable widget for building collapsible application navigation sidebars.

<WidgetExample name="sidebar-basic" />

## Use cases

- **Suitable**: Primary navigation sidebars for dashboards, documentation sites, and desktop apps
- **Suitable**: Layouts that switch between expanded, icon-collapsed, and non-collapsible modes
- **Not suitable**: Cases that only need a regular button group or a short list (use `button` or `menu`)

## Usage

```tsx
import { SidebarProvider, SidebarTrigger } from "@lcui/react"
```

```tsx
<SidebarProvider>
  <Sidebar>
    <SidebarContent />
  </Sidebar>
  <main>
    <SidebarTrigger />
  </main>
</SidebarProvider>
```

## Composition

Use the following composition to build a `Sidebar`:

```
SidebarProvider
├── Sidebar
│   ├── SidebarHeader
│   ├── SidebarContent
│   │   └── SidebarGroup
│   │       ├── SidebarGroupLabel
│   │       ├── SidebarGroupAction
│   │       └── SidebarGroupContent
│   │           └── SidebarMenu
│   │               └── SidebarMenuItem
│   │                   ├── SidebarMenuButton (class)
│   │                   ├── SidebarMenuAction
│   │                   ├── SidebarMenuBadge
│   │                   └── SidebarMenuSub
│   ├── SidebarFooter
│   └── SidebarRail
└── SidebarTrigger
```

## Examples

### Collapsible groups

Place a `SidebarGroup` inside a `Collapsible` and add `data-collapsible-trigger` to its
`SidebarGroupLabel` to toggle the group content by clicking the group heading.

### Icon collapse

With `collapsible="icon"`, collapsing keeps the icons and hides the menu labels; the trigger can expand the sidebar again.

## API Reference

### SidebarProvider

The sidebar state container, which stores the expanded/collapsed state and looks up the nearest provider.

### Sidebar

The main sidebar panel, which handles width, border, and collapse mode.

### SidebarTrigger

A button that toggles the nearest provider; it uses the `panel-left` icon by default.

### SidebarRail

### SidebarMenuButton

`SidebarMenuButton` does not register its own widget; it uses a class contract:

- Add `sidebar-menu-button` to a `button`, `a`, or `RouterLink`
- Put the label in a `text` child with the `sidebar-menu-label` class
- Add the `active` class to the current item
- In the future, `SidebarMenuButton` in `@lcui/react` will create a button with this class by default; when `render` is specified, append the class to the rendered child

## Caveats

:::note
`SidebarContent` does not create a ScrollArea automatically. When scrolling is needed, compose `ScrollArea` and `ScrollAreaContent` inside `SidebarContent`.
:::

:::caution
Floating/inset variants, keyboard shortcuts, and cookie persistence are not supported in the current version. `SidebarInset` is not implemented either.
:::

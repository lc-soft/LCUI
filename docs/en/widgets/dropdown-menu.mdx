# DropdownMenu

A dropdown menu triggers a single command from a set of actions, with support for groups, submenus, checkbox items, radio items, shortcut hints, and destructive actions.

<WidgetExample name="dropdown-menu-demo" />

## Use cases

- **Suitable**: User menus, inline action menus, and command lists that need groups or submenus
- **Suitable**: Settings that show checked or selected state inside the menu
- **Not suitable**: Overlays that need large text input or complex forms (use `dialog` or `popover`)
- **Not suitable**: Cases that only need a regular button (use `button`)

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
} from "@lcui/react"
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>
    <Button>Open</Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent align="start">
    <DropdownMenuLabel>My Account</DropdownMenuLabel>
    <DropdownMenuGroup>
      <DropdownMenuItem>Profile</DropdownMenuItem>
      <DropdownMenuItem>Settings</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuItem>Log out</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

## Composition

Use the following composition to build a `DropdownMenu`:

```
DropdownMenu
├── DropdownMenuTrigger
└── DropdownMenuContent (Portal)
    ├── DropdownMenuLabel
    ├── DropdownMenuGroup
    │   ├── DropdownMenuItem
    │   └── DropdownMenuCheckboxItem
    ├── DropdownMenuSeparator
    ├── DropdownMenuGroup
    │   └── DropdownMenuRadioGroup
    │       ├── DropdownMenuRadioItem
    │       └── DropdownMenuRadioItem
    └── DropdownMenuSub
        ├── DropdownMenuSubTrigger
        └── DropdownMenuSubContent (Portal)
            └── DropdownMenuItem
```

### Shortcuts

`DropdownMenuShortcut` only displays a shortcut hint; it does not bind a real shortcut. While the menu is open, typing a letter triggers typeahead: for example, pressing `s` moves to the menu item that starts with S. It only changes the highlight and never runs the command. Pressing the same letter repeatedly cycles through items with the same initial.

## Caveats

:::note
**Menu content is managed by Portal.** Put `DropdownMenuContent` inside `DropdownMenu`; do not mount it to `ui_root` manually.
:::

:::tip
**Keyboard navigation is built in.** Once the menu is open, use `ArrowUp` / `ArrowDown` to cycle the highlight, `Home` / `End` to jump to the first or last item, `Enter` / `Space` to activate, `ArrowRight` to enter a submenu, `ArrowLeft` to return to the parent, and `Escape` to close the submenu and then the root menu.
:::

:::caution
**Automatic collision flipping is not supported yet.** The menu does not flip or clamp itself against window edges. Set `side` / `align` manually when needed.
:::

:::caution
**RTL is not implemented yet.** The current layout and arrow-key behavior assume LTR.
:::

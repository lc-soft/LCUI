# Field

Composes a label, a control, and helper text into an accessible form field.

<WidgetExample name="field-basic" />

## Use cases

- **Use**: as a unified shell for form fields (label + control + description + error)
- **Use**: when you need to place a label and a control side-by-side in a horizontal layout
- **Use**: to group multiple fields into a semantic group (FieldSet + FieldLegend)
- **Don't**: use for single-line inline text (use the `text` widget instead)
- **Don't**: use in places where native HTML `<form>` submission semantics are required (LCUI does not replicate them)

## Usage

```tsx
import { Field, FieldLabel, FieldDescription, FieldSet } from "@lcui/react"
```

```tsx
<Field>
  <FieldLabel htmlFor="username">Username</FieldLabel>
  <TextInput id="username" placeholder="evil_rabbit" />
  <FieldDescription>Choose a unique username.</FieldDescription>
</Field>
```

## Composition

Use the following composition to build a Field:

```
Field
├── FieldLabel
├── TextInput / Checkbox / RadioGroup
└── FieldDescription

FieldSet
├── FieldLegend
├── FieldDescription
└── FieldGroup
    ├── Field
    ├── FieldSeparator
    └── Field
```

## Caveats

:::note
**FieldLabel's click forwarding depends on the `for` attribute**. You must set `for="input-id"` on the FieldLabel and assign the same `id` to the target control, otherwise the click will not be forwarded.
:::

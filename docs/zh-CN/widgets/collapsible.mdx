# Collapsible

用于展开和收起一段内容的交互组件。

<WidgetExample name="collapsible-demo" />

## 适用场景

- **适用**：产品详情、设置面板、文件树等需要按需显示的内容
- **适用**：内容较多但默认只需展示摘要的场景
- **不适用**：需要模态交互或阻断页面操作的场景（使用 `dialog`）
- **不适用**：仅用于切换少量标签或选项（使用 `select` 或 `radio-group`）

## 用法

```tsx
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@lcui/react"
```

```tsx
<Collapsible defaultOpen>
  <CollapsibleTrigger>Product details</CollapsibleTrigger>
  <CollapsibleContent>
    This panel can be expanded or collapsed.
  </CollapsibleContent>
</Collapsible>
```

## 组合

使用以下组合来构建 `Collapsible`：

```
Collapsible
├── CollapsibleTrigger
└── CollapsibleContent
```

## API 参考

### Collapsible

折叠面板根节点，持有 open/closed 状态。

<FieldTable name="collapsible" />

### CollapsibleTrigger

触发面板切换的节点；也可以给任意后代设置 `data-collapsible-trigger`。

<FieldTable name="collapsible-trigger" />

### CollapsibleContent

面板内容区域，closed 时不参与显示。

<FieldTable name="collapsible-content" />

:::note
`data-collapsible-trigger` 只用于事件绑定，不参与 CSS 选择器。需要样式时请使用 class 或 `collapsible:open` / `collapsible:closed` 状态。
:::

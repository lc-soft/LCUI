# InputGroup

把输入框、图标、说明文字、按钮和下拉菜单组合成统一边框的输入区域。

<WidgetExample name="input-group-demo" />

## 适用场景

- **适用**：搜索框、金额输入、密码框、评论框等需要前置/后置图标或操作按钮的输入区域
- **适用**：需要把输入框和说明、计数、单位、提交按钮放在同一视觉容器内
- **不适用**：只需要一个普通输入框（直接使用 `TextInput`）
- **不适用**：需要多字段表单布局（使用 `Field` / `FieldGroup` 组合）

## 用法

```tsx
import {
  Icon,
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupKbd,
  InputGroupText,
  InputGroupTextarea,
} from "@lcui/react"
```

```tsx
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <Icon name="search" />
  </InputGroupAddon>
</InputGroup>
```

## 组合

使用以下组合来构建 `InputGroup`：

```
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
├── InputGroupText
└── InputGroupKbd
```

## 注意事项

:::note
**focus 与 disabled 由 C 维护**。LCUI 没有 `:focus-within` 和 `:has()`，根容器通过冒泡的 `focus`/`blur` 维护 `focused` status，并通过子控件状态维护 `has-disabled` status。
:::

:::info
**addon 会自动排序**。无论先写输入框还是先写 addon，根容器都会按 `align` 把 inline-start / block-start 放到输入框前，inline-end / block-end 放到输入框后。
:::

:::caution
**block 与 inline addon 不建议混用**。同一 group 混用时，block 布局优先，inline addon 会按纵向布局处理。
:::

:::caution
**一个 group 只放一个输入控件**。addon 点击聚焦只针对第一个匹配控件；disabled 扫描覆盖整个子树。
:::

:::note
**多行输入仍有限制**。`InputGroupTextarea` 基于多行 `TextInput`，XML 变体只展示结构，多行编辑能力由 C/TSX 工厂启用。
:::

# Card

用于承载一组相关信息与操作的容器，由头部、内容区和底部组合而成。

<WidgetExample name="card-basic" />

## 适用场景

- **适用**：表单、账户信息、设置项、文章摘要等需要分组展示的内容
- **适用**：需要在卡片右上角放置编辑、更多等轻量操作的场景
- **不适用**：需要展开/收起的大量内容（使用 `dialog` 或独立页面）
- **不适用**：纯提示信息（使用 `alert` 或 `toast`）

## 用法

```tsx
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@lcui/react"
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Card Content</p>
  </CardContent>
  <CardFooter>
    <p>Card Footer</p>
  </CardFooter>
</Card>
```

## 组合

使用以下组合来构建 `Card`：

```
Card
├── CardHeader
│   ├── CardTitle
│   ├── CardDescription
│   └── CardAction
├── CardContent
└── CardFooter
```

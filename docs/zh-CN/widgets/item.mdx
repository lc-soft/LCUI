# Item

用于设置、列表和快捷操作的通用内容行容器。

<WidgetExample name="item-basic" />

## 适用场景

- **适用**：设置项、资源列表和带操作的内容行
- **适用**：组合媒体、标题、说明和尾部操作
- **不适用**：带选中值和键盘选择逻辑的菜单项

## 用法

```tsx
import { Item, ItemActions, ItemContent, ItemDescription, ItemMedia, ItemTitle } from "@lcui/react"
```

```tsx
<Item variant="outline">
  <ItemContent>
    <ItemTitle>Basic Item</ItemTitle>
    <ItemDescription>A simple item with title and description.</ItemDescription>
  </ItemContent>
  <ItemActions><button>Action</button></ItemActions>
</Item>
```

## 组合

使用以下组合来构建 `Item`：

```
Item
├── ItemMedia
├── ItemContent
│   ├── ItemTitle
│   └── ItemDescription
└── ItemActions
```

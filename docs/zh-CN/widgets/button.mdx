# Button

可点击的按钮部件，通常用于触发某个操作。

<WidgetExample name="button-basic" />

## 适用场景

- **适用**：用户点击执行动作（提交表单、打开页面、切换状态）
- **适用**：工具栏、对话框、导航栏中的交互入口
- **不适用**：不需要交互的纯文本展示（用 `text`）

## 用法

```tsx
import { Button } from "@lcui/react"
```

```tsx
<Button>Button</Button>
```

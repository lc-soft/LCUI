# Dialog

叠加在主窗口或其他对话框之上的模态窗口，其下方的内容进入不可交互状态。

<WidgetExample name="dialog-basic" />

## 适用场景

- **适用**：表单编辑、资料修改等需要在当前页面上完成的任务
- **适用**：展示详情、引导流程等临时打断当前操作的辅助内容
- **不适用**：需要用户明确选择、不允许隐式关闭的确认流程（用 `alert-dialog`）

## 用法

```tsx
import { Dialog, DialogTrigger, DialogOverlay, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter, DialogClose, Portal } from "@lcui/react"
```

```tsx
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <Portal>
    <DialogOverlay>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Are you absolutely sure?</DialogTitle>
          <DialogDescription>
            This action cannot be undone. This will permanently delete your
            account and remove your data from our servers.
          </DialogDescription>
        </DialogHeader>
      </DialogContent>
    </DialogOverlay>
  </Portal>
</Dialog>
```

## 组合

使用以下组合来构建 `Dialog`：

```
Dialog
├── DialogTrigger
└── Portal
    └── DialogOverlay
        └── DialogContent
            ├── DialogHeader
            │   ├── DialogTitle
            │   └── DialogDescription
            └── DialogFooter
```

## 声明式关联

脱离 `Dialog` 子树的普通部件可以用关联键松散绑定，无需嵌套在统一容器中：

```xml title="dialog-xml"
<button data-dialog-trigger="profile">Edit Profile</button>
<dialog-overlay data-dialog-target="profile">
  <dialog-content>
    <text class="text-sm">Clicking X or Esc closes the dialog.</text>
    <button data-dialog-close="profile">Dismiss</button>
  </dialog-content>
</dialog-overlay>
```

:::note

`data-dialog-trigger` 点击切换对应对话框，`data-dialog-target` 指定浮层节点，`data-dialog-close` 点击关闭。同一键可以有多个 trigger 与 close，但只允许一个 target。

:::

## 注意事项

:::caution

**当前实现不包含打开/关闭动画与焦点陷阱。** 遮罩出现后背景内容不可点击，但 Tab 键仍可移动焦点到背景部件。需要严格模态行为时，请在应用层控制。

:::

:::note

按 Esc、点击遮罩空白处或任意 `DialogClose` / `data-dialog-close` 节点都会关闭对话框；点击内容内部不会。Esc 生效要求焦点位于对话框内容子树内（打开时焦点会自动落在首个可聚焦元素；若内容中没有任何可聚焦部件且未注入关闭按钮，Esc 无法关闭）。shadcn 的 RTL 排版依赖 `direction: rtl`，LCUI 暂不支持。

:::

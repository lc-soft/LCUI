# Field

组合 label、控件和说明文字，构成可访问的表单字段。

<WidgetExample name="field-basic" />

## 适用场景

- **适用**：表单字段的统一外壳（label + 控件 + 描述 + 错误信息）
- **适用**：需要在横向布局里把 label 和控件并排
- **适用**：把多个字段组成语义分组（FieldSet + FieldLegend）
- **不适用**：单行 inline 文本（用 text widget）
- **不适用**：要求原生 HTML `<form>` 提交语义的场景（LCUI 没复刻）

## 用法

```tsx
import { Field, FieldLabel, FieldDescription, FieldSet } from "@lcui/react"
```

```tsx
<Field>
  <FieldLabel htmlFor="username">用户名</FieldLabel>
  <TextInput id="username" placeholder="evil_rabbit" />
  <FieldDescription>选择一个唯一的用户名。</FieldDescription>
</Field>
```

## 组合

使用以下组合来构建 Field：

```
Field
├── FieldLabel
├── TextInput / Checkbox / RadioGroup
└── FieldDescription

FieldSet
├── FieldLegend
├── FieldDescription
└── FieldGroup
    ├── Field
    ├── FieldSeparator
    └── Field
```

## 注意事项

:::note
**FieldLabel 的 click forwarding 依赖 `for` 属性**。必须给 FieldLabel 设 `for="input-id"` 并给目标控件设相同 `id`，点击才会转发。
:::
